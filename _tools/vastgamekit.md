VastGameKit is built for simple games that can be embedded in a web page. A game installs it from GitHub as a package, describes its actors, scenes, sprites, and sounds up front, and the engine runs them. It handles:

- Fixed-step updates
- Scenes with cameras
- Sprite animation
- Collision detection
- Keyboard and pointer input
- Audio
- Saved values
- Optional maps made in [Tiled](https://www.mapeditor.org/){:target="_blank" rel="noopener"}

It's the latest version of an engine I've been rebuilding since 2014.
